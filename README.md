# Quansco Limited website

The official public website for **Quansco Limited**, parent brand of:

- **Quanstech Surveillance Solutions** — CCTV, access control, alarms and monitoring
- **Quanstech Multimedia** — photography, videography and documentaries

## Services featured

- Surveillance systems
- Network infrastructure
- Website portals
- E-commerce websites
- Media, photography and videography
- Video documentaries

## Run locally

This is a static website. Open `index.html` in a browser, or serve it locally with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

1. Replace `hello@quansco.com` in `index.html` with the company's real email address.
2. Connect the contact form to a form provider or backend; it currently displays a confirmation message only.
3. Add real project photos and update the copy, phone number and social links.
4. Enable GitHub Pages from **Settings → Pages**, using the `main` branch and the root folder.
